# Portfolio Website

Personal developer portfolio built with React and Vite.

## Tech Stack

- React
- Vite
- CSS
- Motion for React

## Features

- Responsive layout
- Animated hero section
- Interactive project carousel
- Skills, experience, and education sections
- Contact and social links

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The production build is generated in the `dist` directory.
